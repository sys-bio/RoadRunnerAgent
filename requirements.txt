# Dependencies for the hosted (Streamlit) build.
#
# tellurium IS required, despite being heavy. session.py calls te.loada in
# five places, agent.py puts `te` in the agent's namespace and prompts.py
# promises the agent it is there; agent.py also imports matplotlib, which
# nothing else here pulls in. Omitting tellurium saves ~114 MB of wheels and
# breaks the app at import, which is a bad trade. rrplugins (27 MB) is
# Windows-only by its marker, so the Linux install does not pay for it.
#
# numpy is pinned to the series libroadrunner is built against. The first
# hosted deployment segfaulted at startup with no traceback; pinning numpy to
# 2.2.6 - what the development machine runs RoadRunner on - fixed it. Do NOT
# try `numpy<2`: libroadrunner 2.10.0 declares `numpy~=2.2`, so that pin
# cannot resolve and fails the install outright. tellurium asks only for
# numpy>=1.23 and libroadrunner>=2.8, so it does not fight either pin.
#
# libroadrunner resolves by glibc target: manylinux2014 gets 2.7.0, while
# manylinux_2_28 (any current Debian, which is what Streamlit Cloud runs)
# gets 2.10.0. It is pinned rather than floated so a deployment cannot
# silently change the semantics session.py depends on. The deployed probe
# confirms the three behaviours in CLAUDE.md still hold on 2.10.0.

libroadrunner==2.10.0
antimony
numpy==2.2.6
streamlit
plotly
anthropic
openai
tellurium
